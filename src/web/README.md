# src/web — 前端

原生 HTML/CSS/JS，无框架无构建。界面按"作用在哪个区域"切文件，不是按大小硬切——
找一个函数不用在 1200 行里翻。

## 结构

```
index.html      结构：入口页 + 主界面 + 各种弹层
css/base.css    配色变量 / 字体栈 / reset（必须先加载）
css/landing.css 入口页
css/app.css     主界面：顶栏、属性条、装备栏、候选卡
css/account.css 账号抽屉、表单、窄窗口适配
js/core.js      常量 / state / 小工具 / renderAll（必须最先加载）
js/render.js    主界面的全部渲染
js/interact.js  悬停预览、选部位、换装、撤销、详情浮层
js/picker.js    属性选择器、面板校准、导入 simc
js/customize.js 宝石 / 附魔两种模式
js/account.js   登录注册、抽屉、历史、配装存档
js/boot.js      入口页切换、事件绑定、启动
img/            入口页底图
_shot.html      开发用截图探针（不发布，别删，headless 截图靠它）
```

## 加载顺序（重要）

`core.js` 必须最先加载：它定义 `state` 和全局工具函数（`$`、`esc`、`renderAll`），
后面的文件全依赖它。`boot.js` 最后加载，因为它绑定事件、调用 `boot()`。

## 状态管理

前端只有一份全局 `state`（`core.js`），**权威数据来自服务端**——每次操作后
`/api/*` 返回整份 snapshot，前端 `state.snap = d` 再重渲染。前端不自己算属性，
预览和结算就不会漂移（见根 README「状态存服务端」）。

`state.mode` 是右侧面板的三种模式：`equip`（换装备）/ `gem`（插宝石）/ `enchant`（附魔）。
三者共用选中的部位，换部位时模式不变。

## 悬停预览（界面里最核心的交互）

鼠标划过卡片 → 发一个 `preview-*` 请求 → 属性条显示"换上会变成多少"，划走就恢复。
三种模式各有一个：

| 模式 | 接口 | 实现 |
|---|---|---|
| 换装备 | `/api/preview` | `interact.js` |
| 插宝石 | `/api/preview-gem` | `customize.js::hoverCustomize` |
| 附魔 | `/api/preview-enchant` | 同上 |

`hoverCustomize()` 是个通用壳子：拼 URL、发请求、拿到 delta 后涂到属性条上。
**预览请求必须无副作用**——划过一屏可能发十几个，服务端算完立刻回滚。

属性条上的百分比也走这条链路：服务端在快照里给 `s.pct`（按递减算好的百分比），
前端有就用它，没有才退回"评级 ÷ 换算率"的线性估算。旧快照没有这个字段也能显示。

## 宝石面板的三块

```
[孔位条]   1 号孔 / 2 号孔 …… 点一个孔，再点下面的宝石
[打孔器]   只有头/腰/腕出现，开了就变成"已开 1 个孔 · 点这里取消"
[宝石网格] 按属性分类筛选，卡片左侧是游戏图标，名字右边是品质
```

打孔器是个**状态切换**而不是宝石操作：`POST /api/drill` 改的是 `drilled`，
开了之后孔位条会多出一个空孔。取消时如果孔里还插着宝石，服务端会拒绝并提示先拔宝石。

## 属性栏：数字不全时要看得出来

绿字百分比分两截：装备给的 + 天赋/被动给的。天赋那截来自 `spec_stats` 表（专精默认值）
或者玩家填的面板（精确到人）。**表里没有的 35 个专精只有装备那部分**，
这时四项后面会带一个金色小星号，底下一行灰字说明：

```
暴击 356  12.74%*     ← 只有装备，比游戏里低
```

星号不是"这个数错了"，而是"这个数不完整"。不标的话朋友测试时会以为整个工具算不准，
而这恰恰是最容易失去信任的地方。

- 悬停百分比 → `装备 23.15% ＋ 天赋（面板反推）15.00%`，能定位是装备算错还是天赋没算
- 悬停星号 → `这一项未含天赋`
- 填了面板 → 星号消失，右下角变成「校准值 / 含角色基础」（这是给用户的正向反馈）

判定用 `flat_source` 逐项看，**不是**「填没填面板」一个开关——
只填了敏捷没填百分比的话，暴击仍然是残缺的，不能因为"填过面板"就当成准的。

## 视觉规范（防"AI 味"）

- 金 `#d4b478` 只做骨架（线/框/标题），青 `#6ec9d8` 只做交互
- 圆角 3–5px；标题宋体 `font-weight:400`（SimSun 合成粗体在 54px 会糊）
- 输入框只留下划线 + 极淡金渐隐底
- 涨红跌绿（中国股市惯例，见 base.css 变量）


## 常见坑

- **类名别用泛词**。`.top` 撞过装备格内的 `<div class="top">`，`height:50px`/背景/边框
  全漏进格子形成"黑框"。改 `.topbar` 才解。`.top .left .right .bar .body` 这类迟早撞。
- **宝石卡 `min-width:240px`** 不能只写 flex-basis，否则 flex-shrink 压到 170px，名字全截断。
- **名字先截断、品质标签永留**：`.nm` 用 flex，`.t` 负责省略，`.q` 不被裁。
