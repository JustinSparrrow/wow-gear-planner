面板校准

游戏里鼠标悬停属性看到的评级（不是百分比），照着填一遍。
填完之后，顶部的数字就是"角色基础 + 装备"的真实值——之前只算装备， 少了天赋和等级自带的那部分，敏捷会低一千多。

百分比（面板上括号里那个）：建议四项都填。填了才知道这个专精的天赋给了你多少绿字， 换装备时加减才算得准。不填只能套用该专精的通用默认值—— 你的天赋点法跟别人不一样就会差几个百分点，属性栏百分比后面带 * 的就是这种情况。
留空表示该项不可用；点「清除」恢复成只显示装备本体。
